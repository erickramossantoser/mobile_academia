# Controle de Lotação da Academia

Aplicativo Flutter desenvolvido para o Checkpoint 01 da disciplina de Mobile Application Development.

O aplicativo controla a quantidade de pessoas em uma academia com capacidade máxima de 20 pessoas. Ele impede entradas acima da capacidade, impede saídas abaixo de zero e mostra uma mensagem de acordo com a lotação atual.

## Como executar

1. Abra o projeto no Android Studio.
2. Execute `flutter pub get`.
3. Inicie um emulador.
4. Execute o arquivo `lib/main.dart`.
